# Этап 6 — Linux

Состояние: в работе

Оболочка `desktop` для ПК автора с Garuda Linux: окно и настоящий
туннель TUN (D-74). Начат 21 октября 2026 по запросу автора, параллельно
этапам 3 и 4: их критерии выхода не меняются.

## Работы

1. **Мост для ПК** (D-74, D-25): открыть TUN `dppass0`, метка `SO_MARK`
   на сокетах ядра и резолвера Go, копия fd для ядра; библиотека
   `native.py desktop` без тестового входа.
2. **Туннель Linux**: адреса, маршруты, правила и уборка по `TunnelSpec`
   командой `ip`; перехват DNS на любой адрес (`dnsHijackAnyAddress`);
   отказ политики приложений, которую Linux не выражает.
3. **Сборка зависимостей и сеанс**: хранение в `$XDG_DATA_HOME/dppass`,
   геоданные, ядро Xray, подключение по плану, отключение, счётчики.
4. **Окно** (Swing): «Подключение», «Серверы», «Подписки», «Журнал»;
   импорт из буфера обмена и файла.
5. **Пакет**: запуск через `pkexec` с одной `CAP_NET_ADMIN`, действие
   polkit, ярлык, PKGBUILD; архив в ветке сборки.
6. **Позже** (D-74, «Чего нет в первой версии»). Порядок — выбор автора
   (24.10.2026; проверка сети — раньше смены сети, та без неё пуста),
   каждое — своим решением:
   - автообновление подписок (D-39) — сделано: D-77, 0.1.3-dev;
   - наблюдатель сеанса и смена сервера (D-44, D-58) — сделано: D-78,
     0.1.4-dev;
   - проверка сети и режим (D-60, D-64) — сделано: D-79, 0.1.5-dev;
   - смена сети (D-67) — сделано: D-80, 0.1.6-dev;
   - перед ним, по выбору автора (24.10.2026): разбиение к серверу
     (D-68, D-69) — сделано: D-81, 0.1.7-dev; сайты напрямую с
     разбиением (D-72) — сделано: D-82, 0.1.8-dev;
   - режим без сервера (D-73) — сделано: D-83, 0.1.9-dev;
   - раздача (D-51) — сделано: D-84, 0.1.10-dev (только точка доступа
     ПК, выбор автора 24.10.2026);
   - устройство раздачи (D-55) — сделано: D-85, 0.1.11-dev (ввод,
