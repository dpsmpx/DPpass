# Этап 7 — Windows

Состояние: в работе

Оболочка `desktop` для ПК автора с Windows x64: то же окно, туннель —
вход TUN ядра Xray на Wintun, права администратора через UAC (D-97).
Начат 30 октября 2026 по выбору автора; критерии этапов 3–6 не
меняются. Факты — `docs/research/WINDOWS_SHELL.md`.

## Работы

1. **Мост для Windows** (D-97, D-25): платформенные файлы моста по
   `//go:build`; снятие хуков сокетов, добавленных запуском; ключ данных
   под DPAPI; `native.py windows` — DLL mingw-w64 с заголовками JNI
   Temurin; проверка экспорта и импорта DLL. Сделано 30.10.2026: тесты
   моста для Windows — в Wine; DLL в JVM Windows под Wine отвечает на
   JNI; шаг `project.xray-windows`.
2. **Компилятор и политика моста**: вход TUN Windows — адреса,
   маршруты, DNS, `autoOutboundsInterface`, фильтры WFP; поля Windows —
   только на Windows (T11). Сделано 30.10.2026: `SystemTun` в
   `CompilePlan` и `ServerlessPlan`; политика — `checkTunFields`
   платформы.
3. **Платформа Windows в оболочке**: выбор платформы при запуске;
   туннель — у ядра; хранение в `%LOCALAPPDATA%\DPpass`; пробы и смена
   сети; то, чего на Windows нет, — скрыто с причиной. Сделано 30.10.2026:
   `DesktopHost`, `DesktopTunnels` и `DesktopProbeNetwork` с
   реализациями Linux и Windows; `SystemTun` от оркестратора до
   компилятора; маршрут по умолчанию мимо адаптера — от моста; ключ
   данных под DPAPI; проверка сети — только без туннеля (с 31.10.2026 и
   под ним: пробы привязаны к интерфейсу мимо адаптера, D-99); вкладок
   раздачи и устройств раздачи на Windows нет, причина — в «Подключении»
   (раздача — с 31.10.2026, работа 6).
4. **Комплект**: рантайм jlink из Temurin, `wintun.dll`, запускатель
   `dppass.exe` с манифестом `requireAdministrator`, архив и
   `SHA256SUMS`; матрица лицензий и PROVENANCE; ветка сборок
   `windows_debug`. Сделано 30.10.2026: `tools/desktop/windows_package.py`,
   шаг `project.windows-package`. Запускатель сверяет права файлов
   комплекта и чистит окружение JVM (T18). В Wine проверяются запускатель
   (по таблице прав SDDL) и сама оболочка на рантайме комплекта
   (`--windows-self-check`). `NOTICES.txt` — с mingw-w64 и GCC.
5. **Установка и запуск без UAC** (D-100): `setup.exe` в архиве ставит
   комплект в `C:\Program Files\DPpass` со сверкой SHA-256 и
   регистрирует задачу планировщика с наивысшими правами (по выбору — и
   при входе в Windows); ярлык `dppass-start.exe` запускает её без
   вопроса UAC; `uninstall.exe` удаляет. Сделано 31.10.2026; в Wine —
   установка, повторная, подменённый файл, удаление.
6. **Раздача с ПК** (D-101, как D-84 на Linux): вход прокси с паролем на
   адресах частной стороны общего доступа к подключению (ICS) —
   «Мобильный хот-спот» и ICS у адаптера; что раздаётся, мост спрашивает
   у ICS через COM; подсети раздачи — мимо адаптера Wintun. Сделано
   31.10.2026; в Wine — перечисление на поддельных объектах COM и ответ
   моста в самопроверке комплекта.
