# Этап 4 — Интерфейс

Состояние: в работе

## Цель

Интерфейс продукта поверх `DPpassCore` вместо оболочки разработки.

## Работы

1. **Решение о фреймворке** — принято (D-34): встроенные Views без
   AndroidX, своя система дизайна; Activity Result API нет (он только в
   AndroidX) — `startActivityForResult` остаётся.
2. **Экраны**: импорт (файл, ссылка, QR), подписки и их ревизии,
   профили, маршрутизация и DNS, подключение, диагностика и локальный
   отчёт, история активаций с причинами отказов.
3. **Объяснимость**: решение маршрутизации для адреса или приложения
   (`DPpassCore.explain`), план подключения с причинами (D-15),
   исключённые серверы подписки с причинами.
4. **Безопасность интерфейса**: `FLAG_SECURE` на экранах с секретами
   (`docs/SECURITY_MODEL.md`, T9), подтверждение привязки подписки к
   маршрутизации поставщика (D-11), экспорт по умолчанию — с
   отредактированными секретами.
5. **Тексты**: русский и английский; сообщения диагностики — по кодам
   `DiagCode` (D-22); никаких обещаний «незаметности» (D-13).
6. **Доступность**: TalkBack, размеры шрифта, контраст.

Сделано (D-34, D-38…D-43): экраны «Подключение», «Серверы» (поиск,
задержка, порядок), «Подписки» (трафик, срок, расписание, свои
серверы), «Настройки» (политика маршрутизации и DNS, приложения,
постоянный VPN, тема), «Журнал», «О программе» с лицензиями; импорт из
буфера обмена, файла и «Поделиться». Режим «авто» раздельного маршрута
(D-45), защита данных и интерфейса от анализа на устройстве (D-47:
`FLAG_SECURE` диалогов, tapjacking, журнал только по кнопке, случайные
имя пакета и ярлык личной сборки) — написаны. Объяснимость (17.10.2026):
«Почему этот сервер» — план последнего подключения с причинами, исходами
попыток и исключёнными и план следующего; «Почему этот маршрут» — куда
пойдёт сайт, адрес или приложение и по какому правилу; «История
активаций» — версия, источник, сумма, исход и шаг отказа (D-07, D-09,
D-15) — написаны и проверены автором на телефоне 17.10.2026 (0.7.5-dev:
экраны открываются, данные на месте). Осталось: QR; серверы, пропущенные
при обновлении подписки, — на экране (причины пока только в журнале);
проверка доступности и мер D-47 на устройстве.
