# DPpass 0.8.3 RC1

- Android versionName 0.8.3, versionCode 157; stable package and pinned signing certificate.
- Root Zapret2: original upstream NFQUEUE engine and bundled Lua; requires root, NFQUEUE kernel support and iptables. No unrestricted upstream Lua compatibility claim.
- No-root Zapret2: existing protected Xray/Alpine strategy adapter. Full original nfqws2 cannot access Android NFQUEUE with unprivileged VpnService; this is not nfqws2.
- ByeDPI: pinned upstream v0.17.3 executable compiled with Android NDK, MIT license and SHA256 provenance in APK. The local SOCKS listener is authenticated with a per-session random credential. The Android protection broker receives socket descriptors via SCM_RIGHTS and replies only after VpnService.protect succeeds.
- Root ByeDPI: transparent IPv4 and optional IPv6 TCP, root process watchdog and owned iptables rules; UDP is not transparently intercepted; IPv6 requires IPv6 NAT support. The device must provide su and compatible netfilter.
- No-root ByeDPI: TCP and supported SOCKS5 UDP; remote connectivity, DNS handling and socket protection require physical-device verification. Ping/Jitter are unavailable rather than reporting loopback RTT.
- Original 0.8.3 improvements retained. Real mobile Google/YouTube, IPv6, QUIC, root crash recovery and resource usage are not verified. This is a signed candidate, not a completed physical acceptance test.
