# DPpass — единый локальный обучающийся AUTO и необязательная модель

> **Исторический документ (первый прототип).** Скачать модель из GitHub больше нельзя и не требуется. Актуальная реализация создаёт две модели на самом телефоне с выбором размера и поддержкой автовыбора сервера. См. [LOCAL_MODEL_GENERATION_2026-11-22.md](LOCAL_MODEL_GENERATION_2026-11-22.md). Этот текст сохранён только для истории архитектурных решений, а не как инструкция к текущему APK.

## Решение

Сохранить **serverless Android VpnService** и локальный Alpine/PRoot planner.
Ни прокси-сервер, ни VPN-провайдер не нужны. Обычное UDP/TCP-соединение
приложения устанавливается непосредственно через защищённый Android
сокет Xray. Planner решает, как преобразовать только первый TLS ClientHello,
HTTP Host-запрос или QUIC Initial; содержимое TLS не дешифруется.

Встроенный AUTO всегда доступен **без загрузок**. При каждом новом
поддерживаемом соединении используется единственный Go selector
`zapret2Auto`, различающий:

- TLS/TCP: хост по SNI или IP при отсутствии явного SNI;
- HTTP/1 TCP: отдельный ключ `http:<host>`, без TLS-only режима;
- QUIC/UDP: отдельный ключ `udp:<ip>`, `fake-3`, `fake-5`, `pass`.

Учитываются реальные наблюдения от защищённых соединений и выделенные
проверки содержимого на явно перечисленных HTTPS endpoints.
Встроенный селектор по умолчанию перебирает стратегии и закрепляет
только при накоплении сильного сигнала (128 KiB downstream, либо
несколько небольших ответов); кратковременные пустые соединения могут
отозвать предпочтение. Разные хосты/протоколы не объединяются под одним
победителем. Записи ограничены по размеру, сохраняются **только в ОЗУ**
и сбрасываются при переподключении/переустановке списков AUTO; старые
наблюдения не принимаются по generation token.

Отдельный автотест проверяет сертификаты TLS и тип полученного
содержимого для фиксированных Google, YouTube и API/thumbnail целей.
Проверки могут временно подсказать стратегии для **точного** домена
`www.youtube.com` (HTML) или `youtubei.googleapis.com` (транспорт
HTTP API, не реальный authenticated feed) после двух неудач baseline
и двух успешных ответов выбранного приёма. Они не разрешают объявить
успешным видеопоток `googlevideo.com` и не меняют действующие TCP-сессии.

## Необязательная локальная нейросеть

Пользователь сам нажимает **«Скачать локальную нейромодель»** в настройках
экспериментального режима. APK **не содержит весов**. Доступен отдельный
неисполняемый JSON-файл `models/zapret2-mlp-seed-v1.json` в GitHub, из
неизменяемого коммита `e754342d747819f4d1133b32b0426cf3c9354302`.
Android скачивает только по HTTPS, без перенаправлений, максимум 4096
байт, проверяет SHA-256
`a9172f287e6bd4e6ac6ce5cdc3a606cf125b3ec3a8041ebd9ba59b12ac6d7a2b`
и атомарно сохраняет в закрытом каталоге приложения.
Можно удалить файл из интерфейса; без него AUTO работает обычно.
Отсутствие Интернета для скачивания, ошибка проверки или отказ
доступа к GitHub не должны прерывать подключение VPN.

Go принимает только массивы чисел ограниченного диапазона и ровно
фиксированной формы сети **6 входов × 6 ReLU нейронов × 9 выходов**.
Нет скачиваемого кода, Python runtime, облачной модели или API ключа.
6 признаков — категория TLS/HTTP/QUIC, IPv6, наличие доменного имени
и класс CDN `googlevideo.com`; не используются адреса пользователя,
ID приложения, содержимое запросов, строки URL, истории сайтов
или персональные идентификаторы. Модель вычисляет небольшое локальное
относительное предпочтение стратегий **для холодного старта**.
Каждое пятое новое соединение по направлению сохраняет обычное
исследование альтернатив, а накопленный точный per-host winner
имеет приоритет над MLP.

После измерений downstream Go слегка корректирует веса нейросети
ограниченным SGD шагом, без сохранения обучающих примеров или весов
на сервер: 128 KiB и более — сильное транспортное наблюдение,
12–128 KiB — слабое, ноль — возможный отказ, 1–12 KiB — неопределённо.
Это **транспортная эвристика**, не доказательство, что видео в приложении
открылось. Веса меняются **только в памяти** и не отправляются обратно
на GitHub. Seed-модель — инженерная инициализация, **не**
готовая обученная по репрезентативной телеметрии «оптимальная ИИ».
Пользователь может безопасно оставить встроенный AUTO без неё.

## Ограничения и план физических проверок

1. Механизм охватывает защищённые experimental outbounds Xray с
   доступными первой записью TLS, HTTP/1 или QUIC Initial; другие
   протоколы, подписочные профили и обычные приложения вне этого
   serverless VPN не изменяются.
2. Неудачный TCP dial до TLS не содержит данных о стратегии
   десинхронизации; его нельзя «обучить» подбором ClientHello.
   Частые `tcp_dial_unreachable` надо отдельно изучать по IPv4/IPv6,
   DNS, маршрутам и доступности IP. Обход DPI не создаёт
   недостающий физический IP-маршрут.
3. Проверить на реальном Android: встроенный AUTO **без модели**,
   загрузку, проверку файла и активацию на текущем подключении;
   удаление и возврат к встроенному алгоритму; повторное подключение;
   Wi-Fi/MOBILE; перемены сети; поведение при ошибке SHA/без доступа к
   GitHub; отсутствие весов в самом APK.
4. Отдельно проверить YouTube: загрузку ленты, API, thumbnail,
   googlevideo-сегментов и видео. Положительный HTML/HTTP transport
   означает только соответствующую стадию доступа. Нельзя закрывать
   полевые задачи без результатов.

## Инженерные проверки

`tools/xray/bridge/adaptive_nn_test.go` сверяет SHA файла, форму,
бракованные JSON/веса, работу без установленной модели, приоритет
достоверного hostname evidence перед MLP и ограниченное локальное
обучение. В GitHub Actions проходят Go, JVM и APK сборка.
