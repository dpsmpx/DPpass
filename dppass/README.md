# DPpass для Linux — сборка 0.1.31-dev

Собрана из коммита `d98357d` ветки `claude/disable-auto-server-switch-8kn461` (PR в `main`). К коду проекта эта ветка не относится, истории у неё нет, в `main` не вливается. **Не релиз** (`CLAUDE.md`).

Установка на Garuda/Arch: положить `PKGBUILD` и `dppass-desktop-0.1.31-dev.tar.gz` в один каталог и выполнить `makepkg -si`. Запуск — ярлык DPpass или `dppass` (спросит пароль polkit, D-74).

Что нового по сравнению с 0.1.30-dev (D-115): при выключенном «Автопереключении сервера» сервер не меняется сам.
