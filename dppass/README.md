# DPpass для Windows — сборка 0.1.31-dev

Собрана из коммита `d98357d` ветки `claude/disable-auto-server-switch-8kn461` (PR в `main`). К коду проекта эта ветка не относится, истории у неё нет, в `main` не вливается. **Не релиз** (`CLAUDE.md`).

Установка: распаковать `dppass-windows-0.1.31-dev.zip` и запустить `setup.exe` — он спросит права один раз и поставит DPpass в `C:\Program Files\DPpass` (D-100).

Что нового по сравнению с 0.1.30-dev (D-115): при выключенном «Автопереключении сервера» сервер не меняется сам. Пропала сеть — ядро и адаптер `dppass0` остаются, весь трафик заблокирован, над кнопкой питания «Заблокировано — нет сети», уведомление в области уведомлений. Сеть вернулась — соединение восстанавливается тем же сервером (на Windows ядро ради этого не перезапускается: адаптер живёт вместе с ним).
