маршрутизации и подписок, рассчитанный на сети с ограничениями
(`docs/research/RUSSIA_NETWORK_RESTRICTIONS.md`).

## Чем DPpass отличается

- **Конфигурация видна и принадлежит пользователю.** Подписка не
  меняет поведение клиента без согласия: директивы поставщика (смена
  адреса подписки, скрытие настроек, DNS, маршрутизация) отмечаются и
  не применяются; ссылки, скрывающие конфигурацию от пользователя, не
  поддерживаются (D-11).
- **Смысл не меняется молча.** Собственный формат и модель (IR), не
  поля конкретного ядра; то, что нельзя выразить без потери смысла, —
  ошибка с путём в документе, а не «ближайшее похожее» (D-05, D-06).
- **Смена конфигурации — транзакция.** Новая конфигурация становится
  активной только после всех проверок; при отказе остаётся прежняя,
  при «подключено, но данные не идут» — откат к последней рабочей
  (D-07). Подписка — версионированный объект (D-08).
- **Подключение объяснимо.** Сеть оценивается по пробам с бюджетом,
  без залпов (D-14); план кандидатов детерминирован и ограничен, у
  каждой попытки и каждого исключения есть причина (D-15).
- **Честные пределы.** DPpass не создаёт путь, которого нет в сети:
  если сеть похожа на белый список, используются только точки входа,
  отмеченные как доступные из такой сети, а без них клиент прямо
  говорит, что нужно (D-13).
- **Без телеметрии.** Ни аналитики, ни отчётов о падениях, ни
  идентификаторов устройства — даже по просьбе поставщика подписки
  (D-12). Секреты не попадают в журнал и отчёт (D-11).
- **Свой код.** Код, тексты и значки других клиентов не копируются;
  у каждой зависимости записаны лицензия и происхождение (D-20).

## Устройство

Логика — в модулях на чистом Kotlin/JVM, которые собираются и
проверяются без Android SDK; Android-приложение (`app/`) и `cli` —
оболочки над одним и тем же ядром (D-02).

```
             app/ (Android)     cli/ (JVM)
                      \          /
                      connection/          активация, план, подключение, отчёт
    ┌──────────┬───────────┼───────────┬──────────┐
  engine/  subscriptions/  tunnel/   network/   storage/
    └──────────┴───────────┘           └──────────┤
          config/      формат, IR, проверка         │
          routing/     маршрутизация и DNS          │
          core/        IP, строгий JSON, Clock  ◄───┘
          diagnostics/ коды, Outcome, Secret, журнал
```

Модули, их границы и потоки данных — `docs/ARCHITECTURE.md`; формат
документа конфигурации — `docs/CONFIG_FORMAT.md`.

## Сборка и проверка

Нужно: JDK 21, Python 3.11+; для модуля `app` и проверки APK — Android
SDK с платформой 36 и build-tools (`ANDROID_HOME` или `sdk.dir` в
`local.properties`); для проверки компилятора самим Xray — Go 1.21+
(toolchain и модули он скачивает и сверяет сам по `tools/xray/go.mod`).
Без SDK ядро собирается и тестируется, модуль `app` просто не
подключается.

```sh
./gradlew build                     # ядро и все тесты
tools/hostcheck/run.sh --quick      # быстрые проверки без сборки
tools/hostcheck/run.sh              # всё, что можно на этой машине
tools/hostcheck/run.sh --full       # перед слиянием: без Android SDK — ошибка
```

Что проверяет каждый шаг — `docs/PROCESS.md`, «Проверки»; тесты,
корпус регрессий и fuzz — `docs/TESTING.md`. CI нет: GitHub Actions не
используется (D-23), полный прогон делается локально перед слиянием.

## Попробовать на хосте

`dppass-cli` проводит весь конвейер — разбор, проверку, активацию,
маршрутизацию, план и подключение — на фиктивном ядре и синтетической
модели сети, без обращений в сеть (`docs/TESTING.md`, «Модель сети»):

```sh
./gradlew :cli:installDist
cli/build/install/dppass-cli/bin/dppass-cli check tests/data/configs/valid-multi.json
# ACTIVATED revision=1 profile=reality-1 …
cli/build/install/dppass-cli/bin/dppass-cli route tests/data/configs/valid-multi.json --domain www.example.ru
# DIRECT (ru-direct): правило ru-direct
cli/build/install/dppass-cli/bin/dppass-cli connect tests/data/configs/valid-multi.json --condition ALLOWLIST_LIKE
# CONNECTED via domestic-relay
```

Остальные команды (`classify`, `plan`, `subscription`, `export`,
`report`, `bench`) — `dppass-cli` без параметров.
