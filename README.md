# DPpass — отладочные сборки для проверки на устройстве

Эта ветка нужна только для того, чтобы передать отладочный APK на
устройство автора. К коду проекта она не относится, в `main` не
вливается, истории у неё нет.

**Это не релиз.** Релизных сборок до этапа 5 нет (`CLAUDE.md`). Сборка
подписана отладочным ключом машины, где её собрали, и предназначена
только для проверки (`TODO.md`, «На устройстве»).

Что внутри (версия 0.5.0): адаптивная модель устойчивости (D-44),
автоматический раздельный маршрут (D-45), меры против обнаружения VPN
(D-46) и защита данных и интерфейса (D-47) поверх интерфейса и подписок
(D-34…D-43).

Как собрана: `./gradlew -Pdppass.abiSplit=true :app:assembleDebug` на
коде `5200d33` (Android SDK 36, build-tools 36.0.0, NDK 30.0.16248370,
Go 1.24, JDK 21). Библиотека ядра Xray 26.9.30 несжата и выровнена по
16 КБ. Проверено `tools/hostcheck/check_apk.py --abi arm64-v8a`
(разрешения, компоненты, нативный код, набор геоданных, бюджет 42,3 из
46 МиБ) и `apksigner verify` — пройдено. Подпись — отладочный ключ
(`apksigner`), SHA-256 сертификата
`a33824dd9eb55abd0918f997d6e2d9280995cea191c7f5423a309d2a080eb432`.

**Личность пакета.** Отладочная сборка — со стабильным именем пакета
`com.dpsmpx.dppass` (детерминизм проверок). Случайные имя пакета и ярлык
(D-47) — свойство **release**-сборки и требуют ключа разработчика (D-35);
если нужна именно такая сборка, задайте секреты `DPPASS_SIGNING_*` и
соберите release по ABI через `tools/release/sign_apks.py`.

## Установка

1. Скачать APK на телефон: открыть файл в этой ветке на github.com и
   нажать «Download raw file».
2. Открыть скачанный файл и разрешить установку из браузера или
   файлового менеджера. Устройство — arm64-v8a (почти все современные);
   для `armeabi-v7a`/`x86_64` соберите соответствующий APK тем же способом.
3. Если DPpass уже установлен из другой сборки, установка не пройдёт:
   отладочный ключ другой. Сначала удалить старое приложение — вместе с
   ним удалятся его данные.

## Проверка

1. Скопировать свой документ DPpass в буфер обмена, затем «Импорт из
   буфера обмена» → «Поднять туннель».
2. Для подписки — экран «Подписки» → добавить по адресу, «Обновить и
   применить».
3. Журнал — только кнопкой «Копировать журнал» (D-47: автокопии больше
   нет).

**Важно (честный предел):** подключение через туннель к реальному
серверу на устройстве ещё не проверялось (этап 2, `TODO.md`); это первая
сборка 0.5.0 для такой проверки, а не готовый к повседневной работе
продукт.
